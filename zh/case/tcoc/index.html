TCOC：官方網站與品牌形象重新設計

主導產品設計 & 前端開發 | 與教會利害關係人及後端工程師協作

3 個月 Figma HTML CSS JS

不受時間限制的長青架構

從「活動導向」轉為「價值導向」的資訊架構，徹底解決網站內容過時且難以維護的負擔。

用設計解決公關危機

敏捷調整 UI 策略，建立專屬的「透明度專區」展示財務與神學基礎，正面回應網路謠言。

順暢的轉換體驗

整合 LINE 官方帳號入口，成功在站內原生處理超過 100 件查詢。

專案挑戰

80%

內容老化率

舊網站極度缺乏維護，首頁塞滿了早已過期的短期活動資訊。高達 80% 的內容老化率不僅讓網站形同虛設，更讓年輕族群產生極大的距離感與跳出率 (Bounce Rate)。
90%

頁面跳出率

對於「婚姻輔導」等高心理門檻的服務，舊版網頁僅提供生硬的收費標準與冰冷的公家機關式表單。極高的操作摩擦力導致帶有防備心的使用者望而卻步，線上轉換率幾乎歸零。
1

場品牌信任危機

開發期間組織遭到網路謠言攻擊，被惡意質疑為「空殼詐騙」。網站急需從單純的資訊佈告欄，轉型為能提供社會證明、建立國際公信力的戰略公關樞紐。

目標與指標

UX 與商業策略

長青資訊架構

用品牌邏輯取代短期活動。專注傳遞核心信仰價值，建立不受時間限制的內容基底，將後續維護成本降至最低。
轉換率優化

心理安全感與無摩擦漏斗

透過場域照片與深度理念建立信任。導入 LINE OA 取代高摩擦力的傳統表單，打造高轉換率的軟著陸體驗。
技術與公關

敏捷防線與前端動畫

敏捷部署「透明度專區」化解公關危機；並運用 HTML/CSS/JS 實作滾動視差與微互動，徹底打破傳統死板印象。

UX 規劃

從資訊架構重組到化解危機的戰略佈局

定義長青架構

為了擺脫殭屍網站的宿命，我對標了 The Hope 等現代化網站，發現他們皆採用「品牌化策略」吸引年輕族群。我向決策主管（牧師）提案並迅速達成共識：放棄易過時的活動佈告思維，轉向 Evergreen Content。
為避免網站流於空殼，我引導教牧團隊盤點出具備持續性的「標誌性活動」，將其轉化為網站上的核心「服務產品」。這項戰略不僅奠定了專業基礎，更免除了未來 80% 的日常維護負擔。

修復轉換漏斗

我發現舊版「婚姻輔導」頁面擁有極佳的自然搜尋流量，但冰冷的收費標準與傳統表單造成了嚴重的放棄率。
我決定將報名頁面拆解為「建立信任 ➔ 輕鬆諮詢」兩步漏斗。在頁面加入空間實景與深度理念來安撫使用者，並廢棄了高摩擦的表單，將 Call-to-Action (CTA) 全面導向 LINE 官方帳號，提供匿名的軟著陸管道。

化解「空殼詐騙」公關危機

開發期間，組織遭遇惡意謠言攻擊。客戶緊急提供了會計師認證、監事會名單、神學基礎三份自清檔案。
為建立絕對的品牌公信力，他們給了我關於監理事會和會計師查證的PDF，希望可以提供給瀏覽者觀看。但只有冰冷的PDF似乎無法呼應品牌原本的格調，而且信服力也欠缺。我運用 Agile UX (敏捷設計) 迅速調整企劃，將這些資料以企業級文案包裝為「透明度防線」，準備以不卑不亢的姿態正面粉碎空殼謠言。

設計風格

視覺識別：手繪 Icon 與大膽活潑的品牌重塑

設計迭代

運用 UX 學理，將策略轉化為具體的介面解法

迭代 1：解決「內容老化」的視覺策略

流水帳導致的品牌劣化
舊站生硬的活動佈告欄排版不僅容易過時，更充滿傳統組織的說教感，完全無法傳遞品牌的溫度與現代感。
價值導向與 Custom Icons
我改用第一人稱對話式文案包裝「核心服務」。同時，大量導入手繪 Icon 建立大膽、活潑且自成一格的 Visual Identity (視覺識別)，有效降低了使用者的防備心。

迭代 2：降低 Cognitive Load (認知負荷) 的漸進式揭露

高門檻服務的轉換阻力
在設計「婚姻輔導」頁面時，若將所有理念、費用、場地細節全塞在一起，會造成極大的認知負荷，讓使用者在點擊前就疲勞跳出。
Progressive Disclosure (漸進式揭露)
在主頁以大面積的「真實輔導空間照片」與 FAQ 優先建立心理安全感；深度的理念收納至次級頁面。最後結合 LINE 按鈕，成功設計出 Frictionless (無摩擦) 的轉換體驗。

迭代 3：利用 Social Proof 化解公關危機

突發的網路信任崩盤
開發期間遭到惡意謠言攻擊。持份者急需一個官方管道來澄清神學背景與財務透明度，最大的挑戰是如何設計得具備權威感又不失現代風格。
打造透明度防線與權威背書
將個人故事區塊替換為企業級的「透明度專區」。利用跑馬燈動畫展示全球分支地圖，透過強大的 Social Proof 在視覺上直接具象化其國際根基，完美達成了化解危機的目標。
