Iteration 1: Solving the "Sync vs. Custom" Conflict

The "Central Hub" Problem
Initially, I centralized Macro and Lighting settings in one main dashboard. However, users found it impossible to map lighting effects to specific physical buttons on different devices, causing confusion.
The Decentralized Fix
I moved these settings into individual device tabs. This solved the mapping issue but broke the "Sync Lighting" feature, as the system didn't know which device should be the "master."
Final Hybrid Architecture
We separated the logic. Individual settings remain in device tabs, while "Global Sync" exists as an independent override layer. When Sync is on, it overrides individual settings; when off, individual settings return.

Iteration 2: Unifying the Profile Ecosystem

Fragmented Experience
Originally, "Local Profiles" were fixed on the sidebar, while "Community Profiles" lived on a totally different page. This disconnected the "Search → Download → Apply" workflow.
Unified Profile Manager
I merged both into a single "Profile Hub." Users can now switch between Local and Cloud views instantly.

Iteration 3: Improving the visual scanning

Visual Optimization
I redesigned the profile cards by prioritizing "Device Model" tags and adding "Game Icons" for faster scanning. I also reduced the cover image height to display more items per scroll, improving browsing efficiency.
