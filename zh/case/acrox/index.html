目標與指標

體驗戰略

架構重構

解開軟硬體邏輯死結

開發混合式覆蓋架構，在各種複雜的電競硬體設備上，完美平衡「全域同步（批次修改）」和「個別客製化」的優先級衝突。
防呆結構

消除導覽迷航感

在有限的筆電螢幕空間中，優化介面佈局與視覺資訊層級 (Visual Hierarchy)，讓使用者不需要去猜測設定藏在哪裡，降低學習門檻。

UX 戰略決策

在「客戶商業期望」與「真實玩家體驗」間的權衡

產品健檢：從視覺美化轉向邏輯補完 (UX Audit)

挖掘工程思維背後的隱蔽痛點
一開始客戶只發包了現有 Wireframe 的「視覺美化」。但我透過啟發式評估盤點後，發現原稿純粹是工程思維的產物，漏掉了大量玩家真實的使用情境。如果只做表面美化，產品上線後絕對會面臨極高的操作挫折。
所以我說服客戶暫停視覺開發，先進行深度 UX 診斷，並主動補齊了 10+ 項核心功能。例如：

無縫的設定檔社群機制
原版將「本機端」與「線上端」設定檔完全割裂，忽略了玩家將本機設定公開分享的剛性需求。我重新規劃了上傳與分享流程，並新增「種類」、「適用遊戲」等標籤，大幅提升設定檔的可尋性 (Findability)，讓新手能精準一鍵複製神人設定。
全裝置適用的「設定細節列表」
原版僅有「巨集」具備總覽列表，其他硬體（如具備多重設定的滑鼠）只能透過點擊螢幕中間的設備示意圖來盲探，造成嚴重的資訊隱蔽 (Hidden Information)。透過任務分析，我主動提出並新增了全裝置通用的列表視圖，讓玩家能以全局視角快速管理所有複雜配置。

混合式架構：解開「全域 vs. 單機」的權限死結

相互覆蓋的設定衝突
針對燈效同步，原本構想是把所有設定塞在一起。但這會讓人分不清現在改的是「全部設備」還是「單一滑鼠」，缺乏明確的層級會讓玩家辛苦調好的單一燈效莫名被洗掉，產生極大挫折感。
建立明確的 Override 覆蓋機制
為了解決這個硬體控制的死結，我提出建立明確的覆蓋機制 (Override Logic)。將全域同步抽離成獨立的覆蓋層，打開同步時覆蓋單機設定，關閉則恢復。雖然增加了開發複雜度，但確保了軟硬體整合 100% 不打架。

利害關係人妥協：巨集邏輯的標準化降維打擊

反直覺的商業需求限制
巨集本質上是跨硬體的指令，我強烈建議將其獨立為全局管理頁面。但客戶基於「市場考量」，堅持要將巨集歸屬在個別裝置的頁籤之下。這會讓玩家陷入「在滑鼠頁面裡設定鍵盤按鍵」的邏輯錯亂。
透過 UI 標準化降低學習成本
在無法改變商業決策的情況下，我做了必要的妥協。我將巨集的 UI 模組完全標準化 (UI Standardization)，透過跨裝置一致的排版設計，來降低這種「反直覺架構」帶來的學習成本與認知摩擦。

設計風格

視覺識別：風格定調與介面元素

設計迭代與微調

從大架構的佈局，到細節元件的資訊層級，展現極致推敲。

迭代 1：結構上的防迷航優化 (三階段佈局演進)

零碎的佈局導致視覺跳動
為了在筆電狹小螢幕內塞入龐大設定，基礎設定區塊的位置一改再改。由於每個裝置的設定項目多寡不同，導致排版會隨著切換忽高忽低，產生嚴重的視覺跳動與認知摩擦 (Cognitive Friction)。
導入固定的基礎設定和設定列表
為了改善視覺跳動問題，我導入了固定的基礎設定區域和統一的設定列表，使不同裝置上的排版更加一致，減少使用者的認知負擔。

而且基礎性的設定應該反而是使用者最常接觸的，在顯示的層級優先順序上要提高，固定的排版也會減低使用者不耐煩和新手找不到基礎設定的問題。
基於空間一致性的三欄式佈局
我決定犧牲一點裝置預覽圖的空間，統一改為「三欄式佈局」，將基礎設定固定在右手邊。透過強大的空間一致性 (Spatial Consistency)，讓使用者不需猜測設定藏在哪，徹底消弭了切換設備時的視覺迷航。

迭代 2：設定檔詳情頁的資訊重心翻轉

滿版封面導致的瀏覽限制
在設定檔詳細頁面，原本為了美感設計了滿版精美封面大圖。但 Review 時發現，最重要的「設定參數細節」全被擠到了折疊線 (Above the fold) 之下，需要大量無效的滾動。
30/70 分區提升資訊密度
對專業玩家來說，快速比對參數遠比欣賞圖片重要。我果斷推翻原設計改採「左右 30/70 分區」。左側保留基本資料，右側一次性展開所有參數，讓資訊密度 (Information Density) 回歸專業工具的本質。

迭代 3：設定檔卡片的掃視效率 (Scannability) 提升

封面主導造成的資訊層級隱沒
在原版的卡片列表中，圖片佔據了絕大比例，導致最重要的設備型號與適用遊戲等文字標籤變得不顯眼，玩家很難在快速滑動中找到自己需要的設定檔。
優化視覺層級與資訊密度
我重新定義了視覺層級 (Visual Hierarchy)，將「設備型號」標籤往前拉，並加入「遊戲圖示」提供視覺線索。同時刻意縮減封面圖片高度，確保一次畫面滾動中能容納更多卡片，極大地提升了尋找與瀏覽的掃視效率。
